# خدمات النظام

- `users.js`: المستخدمون، كلمات المرور، تسجيل الدخول والصلاحيات ومسح البيانات.
- `financial-years.js`: السنوات المالية والإغلاق والترحيل بين السنوات.
- `vouchers.js`: سندات الصرف العامة وربطها بالحسابات البنكية.
- `closing.js`: حسابات الإقفال وحفظ تقارير الإقفال.
- `settings.js`: إعدادات التطبيق واستيراد البيانات القديمة.

يعمل `../system.service.js` كواجهة موحدة متوافقة مع قنوات IPC الحالية.
