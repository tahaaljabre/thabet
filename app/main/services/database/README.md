# طبقة قاعدة البيانات

- `connection.js`: إنشاء اتصال SQLite وإعداد معالجات الأخطاء.
- `schema.js`: إنشاء الجداول والترحيلات المتوافقة مع قواعد البيانات القديمة.
- `index.js`: أدوات الاستعلام والإغلاق والتدقيق وفحص السنة المالية.
- `../database.js`: واجهة توافق تُبقي استيرادات الخدمات القديمة تعمل.

## قاعدة مهمة

أي جدول جديد يجب إنشاؤه باستخدام `CREATE TABLE IF NOT EXISTS`، وأي عمود جديد يجب إضافته من خلال ترحيل يتحقق من وجوده أولًا. لا يجوز افتراض أن قاعدة بيانات العميل تحتوي آخر مخطط.
