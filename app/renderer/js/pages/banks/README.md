# قسم البنوك

- `index.js`: تحميل بيانات البنوك وتحديث البطاقات والقوائم.
- `accounts/form.js`: إضافة الحساب البنكي وتعديله وحذفه وحفظ ربط المبيعات.
- `transactions/index.js`: إضافة الحركات البنكية وتعديلها وحذفها وطباعة سند الحركة.
- `statements/index.js`: إعداد وطباعة كشوف الحسابات البنكية.

الملفات تعمل كسكربتات المتصفح التقليدية حاليًا، لذلك يجب الحفاظ على ترتيب تحميلها في `index.html` إلى أن يتم تحويل القسم كاملًا إلى ES Modules.
