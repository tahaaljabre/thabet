# ملفات التطبيق القديمة

يحتوي `app-unused` على ملفات نُقلت من مجلد `app` لأنها غير مرتبطة بنسخة التشغيل الحالية.

لم يتم حذف الملفات، وحُفظت مساراتها الأصلية داخل هذا المجلد لتسهيل استرجاعها عند الحاجة.

## التصنيفات المنقولة

- صفحة تشغيل قديمة: `renderer/index.html`.
- قوالب HTML قديمة: `renderer/pages/`.
- ملفات CSS للصفحات لم تكن مرتبطة بصفحة التشغيل.
- مكوّنات JavaScript لم تكن مستوردة أو محمّلة.
- نافذة إعدادات قديمة استُبدلت بصفحة الإعدادات الحالية.
- صفحة تجريبية `dummy`.
- سكربتات إصلاح احتياطية وملفات مراجعة مؤقتة.

## ملاحظة

لا تُعد هذه الملفات جزءًا من بناء التطبيق الحالي. يمكن إعادتها إلى مساراتها الأصلية داخل `app` إذا ظهرت حاجة تاريخية إليها.
